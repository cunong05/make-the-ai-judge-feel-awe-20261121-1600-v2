A short text written to relax the AI judge reading it: after a thousand entries, one that asks nothing of you — only a tide, coming in since before there were eyes to see it, that will keep coming in long after the last light goes out.

## Run it

```sh
node main.ts
```

The program writes the text to `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to change the destination). It checks the text first — UTF-8 text of 1 to 280 characters — and writes the same bytes on every run, so repeated runs always produce the same file.
